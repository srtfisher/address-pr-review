# Changelog

## 0.8.0

- Mark an inline review thread to resolve with the new "Resolve thread" button or `r`. When you approve, the agent posts your reply (if any) and then resolves the thread on GitHub. It works with "Don't reply" too, to resolve a thread without saying anything.

## 0.7.0

- On very wide screens (1760px and up), an item with a diff shows your reply in a column beside the code instead of below it.

## 0.6.0

- Type `:` and a couple of letters in a reply to pick an emoji, like on GitHub. It inserts the emoji character.

## 0.5.0

- Buttons show their keyboard shortcut in a small key box, so you can learn them as you go.
- While an item is marked to go back to the agent, its buttons are now "Cancel" and "Send back to the agent…", which opens the finish dialog. Clicking "Back to the agent" used to undo the choice instead.

## 0.4.0

- Choosing "Don't reply" on a thread now shows the confirmation note with a "Next review note" button, the same as sending does.
- Press `f` to open the finish dialog from anywhere on the page.
- The finish dialog focuses its main button when it opens, so Enter approves your replies or sends items back to the agent.

## 0.3.0

- After you decide on a reply, a notice offers a button to move on to the next review note.
- Press `?` to see every keyboard shortcut.

## 0.2.0

- Renamed the project to `address-pr-review`.
